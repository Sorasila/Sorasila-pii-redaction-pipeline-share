# รายละเอียดที่ดินพิพาท (ข้อมูลสังเคราะห์สำหรับทดสอบ ไม่ใช่ที่ดินหรือบุคคลจริง)

| รายการ | รายละเอียด |
| --- | --- |
| ที่ดินโฉนดเลขที่ | 12345 |
| เลขที่ดิน | 678 |
| หน้าสำรวจ | 4321 |
| ระวาง | 5036 IV 0000-00 |
| ที่ตั้ง | ตำบลทดสอบ อำเภอสมมุติ จังหวัดตัวอย่าง |

ที่ดินแปลงนี้เดิมเป็นของนายทดสอบ สมมติชัย ต่อมาได้จดทะเบียนขายให้แก่บริษัท ทดลองพัฒนาที่ดิน จำกัด
เมื่อวันที่ 10 มีนาคม 2560 โดยมีนางสมใจ ตัวอย่างดี เป็นพยาน

ผู้รับมอบอำนาจของบริษัท ทดลองพัฒนาที่ดิน จำกัด ติดต่อได้ที่อีเมล somsmut.thodlong@example.com
หรือโทรสาร 02-000-0000 การชำระค่าธรรมเนียมให้โอนเข้าบัญชีเงินฝากเลขที่ 000-0-00000-0

สำนักงานที่ดินจังหวัดตัวอย่าง สาขาอำเภอสมมุติ ได้ตรวจสอบสารบบที่ดินแล้ว พบว่าโฉนดเลขที่ 12345
ยังมีภาระจำยอมตามหนังสือที่ กขค 0000.0/0002 ซึ่งต้องแจ้งให้ผู้มีส่วนได้เสียทราบก่อนดำเนินการ

ข้อเท็จจริงเกี่ยวกับห้างหุ้นส่วน ข. ซึ่งเป็นผู้เช่าที่ดินบางส่วน ไม่ปรากฏในสารบบ จึงไม่อาจรับฟังได้
